## 三点十一、Agent 检索接口 kb.py（2026-11-09 09:20）

**面向 AI 调用的统一接口**，把 8 项改进全部实现：

| 子命令 | 作用 |
|---|---|
| `search` | 语义检索，JSON 输出，token 预算，文档级聚合 |
| `page` | 拉整篇文章的小节清单（L0 摘要 + 全部父级） |
| `neighbors` | 取命中块的相邻块（seq 窗口） |
| `meta` | 数据集元信息（快照时间、模型、切块参数、表行数） |
| `skills` | **查询 skill**：列出可用 skill（扫描 `~/.agents/skills`），设计为可移植包 |

### 用法

```bash
# 检索（JSON，给 agent 用）
python scripts/kb.py search "唐朝科举" --tables zh --k 3 --json --max-tokens 1500

# 代码检索（自动带签名）
python scripts/kb.py search "debounce" --tables code --json

# 命中后深入
python scripts/kb.py page 3887708 --table zh --json
python scripts/kb.py neighbors "zh:3887708#3" --seq 3 --json

# 元信息 / 技能
python scripts/kb.py meta --json
python scripts/kb.py skills --query "视频"
```

### 返回结构（search）

```json
{
  "query": "...", "snapshot": "2025-08", "tables": ["zh"],
  "results": [{
    "doc_id": "3887708", "parent_id": "3887708#3",
    "title": "科举", "section": "各地情況 > 中國",
    "score": 0.9214, "text": "...", "n_tok": 467,
    "url": "...", "license": "CC-BY-SA-4.0",
    "signature": "function debounce(func, wait) {",   // 仅代码
    "page_summary": "科举是一種通過考试...",           // L0 导语
    "hit_seqs": [0,2,3,4,5,6]
  }],
  "total_tokens": 1039, "max_tokens": 2000, "truncated": false
}
```

### 关键实现细节

1. **文档级聚合**：同一 `doc_id` 的多个小节合并成一条，`sections` 字段记录命中过哪些小节
2. **token 预算**：累加 `n_tok`，超 `--max-tokens` 就截断并置 `truncated=true`
3. **代码返回切片**：代码的父级是整文件，只返回命中符号的 `[start_idx:end_idx]` 切片（避免塞 5KB 文件）
4. **签名提取**：从块文本前 25 行按语言正则匹配，且校验包含 symbol 名（防偏移错位返回错误签名）
5. **L0 摘要**：每条结果附 `page_summary`（文章首段），让 agent 判断"这篇讲什么"

### 实测

| 场景 | 结果 |
|---|---|
| `search "唐朝科举" --json` | 3 条结果，1039 tok，科举/唐朝/中国科举制度 ✅ |
| `search "debounce" --tables code` | 签名 `function debounce(func, wait, context)`，97 tok ✅ |
| `page 3887708` | 25 个小节清单 ✅ |
| `neighbors "zh:3887708#3" --seq 3` | seq 2/3/4 三块 ✅ |
| `meta` | 17 条元信息 + 5 张表行数 ✅ |
| `skills` | 12 个 skill ✅ |

**`skills` 的定位（可移植查询包）**：

`kb.py skills` 不依赖任何 harness API，只做两件事：扫目录、解析 SKILL.md 的 frontmatter。

| 嵌入 | **ONNX int8 CPU**（不用 torch） | 启动 355ms vs 9396ms；无 CUDA 依赖 |

### 表结构

          verified, evidence_ref, verified_at, scope, tags, entities,

### 权限模型（按端点，不按模型自报）

| endpoint_trust | model_class | 结果 |
|---|---|---|
| unverified（未登记） | 任何 | **draft** |

| declared | small | **draft** |
