## 总目标

**给 pi 的本地长期记忆插件，全离线、可分发。**

三条核心主张：

1. **一套嵌入模型干三件事** —— 检索、建图、判冲突都用同一个 384 维向量，
   不抽实体、不做本体、不引入第二个模型
2. **缓存友好的注入** —— 稳定内容进 system sections（首次之后零成本），
   会变化的内容进 tail（每次只付该段）
3. **零 LLM 写入** —— 写入是 嵌入→查重→落库，2ms；
   需要模型时只在到点提醒一句，piggyback 不额外开轮

当前主线：**C1 段索引**（摘要 + 指针，不折叠上下文）。

### 2026-11-10（缓存实验：注入通道规则被推翻重写）

**做了什么**：用 env 开关让 system section 每轮变化，跑两组各 10 轮对照。

**实测数据**：

| 组 | 每轮 input | cacheRead | system 条目 |
|---|---|---|---|
| section 稳定 | 219–525 | 3968→6272（持续增长） | 1 |
| section 每轮变 | 2319–4481 | **卡死 2048** | 10（每轮一个补丁） |

**结论**：

1. 补丁确实只含变化的 section，位置在对话末尾
2. **但缓存从该 section 的位置起全部失效**——2048 正好是 section 之前的长度
3. 补丁虽然追加在末尾，开头的 system 消息被重建了

**规则修正**：

```
内容永不变化  → system sections（首次之后 0 成本）
内容会变化    → tail（每次只付该段 token）
```

之前"能稳定的都放 system"太粗，段索引/域激活必须走 tail。

**成本测算**（deepseek-v4.1-flash：miss $0.15/M，hit $0.003/M，1/50）：

| 场景 | 增幅 |
|---|---|
| 20K / 500 | +15.5% |
| 50K / 2000 | +4.6% |
| 100K / 2000 | +3.5% |
| 150K / 3000 | +2.3% |

100 轮 / 100K 上下文：基线 $0.0600 → 有插件 $0.0621，**多 2 厘钱**。

**关键发现**：稳态开销 88% 来自 tail 每轮 123 token；
**一次重锚 = 25 轮正常开销**（100K 上下文下 $0.015）。
优化优先级应该是**省重锚**，不是省注入。

### 2026-11-10 凌晨（harvest 移出关键路径 + 会话锚点）

**决策**：读取侧不后台化（10ms 不是瓶颈，推送会毁掉缓存契约）；写入侧后台化（harvest 真在打断主线）。

- 线程内钩子从 3 个收敛到 **1 个**（只留压缩前）
- 会话结束 → 导出转录 → **SQLite 队列** → detached 进程，pi 退出后继续跑

- 关机恢复：`session_start` 自动 `--drain`，任务在 SQLite 里不丢

- **会话锚点**：`mem_anchors` 表 + `mem_anchor` pi 条目，给短期工作记忆留挂载点

### 2026-11-10 凌晨（评测方法论踩坑）

试了「用原始提问做查询、蒸馏记忆做真值」的自动评测，**失败，0% 命中**。

原因不是检索差，是**真值错**：
- 记忆来自助手某轮回答里的一句，但同一轮的**用户提问往往问的是别的事**
- 例：问「ModelScope 下载 20M 正常吗」→ 期望记忆却是「curl -C - 遇到不支持 Range 会损坏文件」
- 例：问「我的记忆文件你觉得我是怎样的人」→ 期望记忆是「重锚改写 system」

**结论：`turn` 粒度的 provenance 不能当真值。** 助手一轮回答覆盖多个话题，按轮对齐必然错位。

可行的评测方式只剩两种：
1. **人工出题**：用户写 15-20 个真实会问的问题，我盲跑（推荐）
2. **LLM 反向生成**：给记忆让模型写问题（本次本地模型已停，未做）

## 关键决策（不要再翻案）

| 决策 | 理由 |
|---|---|
| SQLite 而非 LanceDB | 启动 248ms vs 1839ms |
| ONNX int8 而非 torch | 启动 355ms vs 9396ms，省 4GB |
| 不做 content 归一化（hybridWeight） | 原作者盲测失败 |
| 不做同义边 | 几何不可区分，用 near_dup 替代 |
| 两库完全独立 | 依赖/生命周期/权限都不同 |
| `retrieve` 只返回 JSON | 不假设宿主形态 |
| 重锚只写尾部 | 改 system = 全上下文 cache miss |
| 图从向量长出来 | 不抽实体、无本体、零 LLM 写入 |
